# 手机麦克风主动让麦测试版

基线：TaoSheng v0.3.0，提交 32dd3f6ece2fe25c4684247e2e7e7349be7f8f0f。

## 改动
- 手机内置麦克风与现有蓝牙通话麦克风一样，在系统报告其他应用录音时 stop/release AudioRecord。USB、有线输入策略不变。
- 看门狗在阻塞读取时也能触发让麦；停止后等待其他录音结束，并留 500ms 冷静窗口再重开。
- 未增加权限、无障碍监听、输入内容读取、网络端点或上传。未修改采集服务手动暂停、回放持有状态；等待可被协程取消，不主动清除暂停。
- 保留包名 app.resound、版本号 77；版本名 0.3.0-micfix.1。

## 重要限制
- 仅能观察 Android 已登记的录音活动，无法读取另一个应用尚未发起的麦克风请求。如果 Typeless 预检查发现占用后直接报错，没有登记录音，此方案不会触发，仍需真机验证。
- 其他 App 开始录音即主动让出，而非等涛声被系统静音，所以让麦期间涛声不会录下其他 App 的交互声音，这是本次优先输入法的预期变化。
- 安卓构建与单元测试不能替代 Samsung/Typeless 真机兼容性和时序测试。
- 此包不持有原作者私钥，不能覆盖安装官方签名 APK。相同包名不代表相同签名。不要卸载原版或删除数据以尝试安装。若需要无损覆盖，必须由作者使用原签名构建该补丁，或具备平台允许的有效签名继承关系。
- 不把这次功能补丁或源码审阅表述为安全认证。第三方预编译原生库和原有网络行为未由此消除。
