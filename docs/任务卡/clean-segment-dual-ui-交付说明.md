# 同一原始录音两版文字：界面

从 2970a97 基线重新实现，没有复用跨会话方案。

- 自定义转写下可填写对齐完整地址，留空关闭；复用手机分人模型下载/开关，展示最近处理状态。
- 原话历史、事件原话、日记、待办来源、问问原话引用、导入详情、技能原话引用、声纹样本/原话、展开播放器字幕及首次试录原话使用同一个两版组件。
- 整体版按已有 segment ID 查询，每个文件展示一次完整文本，不创建说话人、原话 ID 或逐句时间。引用位置明确告知整体文字可能包含该句之外的上下文。
- 缺失、等待、运行、失败、已删除分别说明；重转写期间的旧成功文本标为旧结果。切分为空而整体有字时显示未自动整理提示。
- 切分版保持原有播放、声纹标记与修正行为；整体版只读，可选择复制，不把编辑投射到另一版。
- 播放器收起状态仍为当前句快捷预览，点击展开显示切换；整体文本区域可滚动，不挤掉播放控制。
- 已导出文件的 SRT 预览仍展示该产物自己的字幕（产物没有 segment 映射），不混用当前数据库文字。导出/复制原话的既有语义未改。

验证：UI diff whitespace 检查通过；编译由集成负责人统一执行，未进行手机 Compose 交互测试。

手机验收：切换期间反复关闭/打开，播放器滚动长整体文本，A 空/B 成功，B 失败保留旧结果，声纹来源切换时不误把整段归给单人，重新转写后结果刷新。
