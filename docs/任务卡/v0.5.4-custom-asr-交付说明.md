# v0.5.4 自编版交付说明

基线：typeless-micfix b08dca5752c0ae035b5895b8b4a29427d7f17f6e，合入正式 v0.5.4 dcbbd6fac984d2359388fa300b1b34f8013e47cb。安装包 app.resound，0.5.4-custom-asr.1，versionCode 95（高于上游 94 和上一自编版 90）。不改 main。

## 变更与兼容

- 保留 Typeless 麦克风让出、本机分人、可配置对齐、每原始 segment 独立 A 切分版/B 整体版、全界面版本切换、整理输入、备份删除与后台调度。原录音、暂停、VAD、会话边界不变；不拼接缺失睡眠音频窗。官方 APK 自动检查、下载和安装入口继续禁用。
- 上游新增原话手改、会议中逐块整理、千问转写与 token 用量、自适应流式模型处理、录音长期保留/文件夹推送。10 分钟块只用于专题摘要；双 ASR 仍按原始录音执行。
- TopicBlockProcessor 继续等待 B，B 失败阻断，用户显式只 A 才允许跳过 B；只有 B 没有 A 时不伪造原话。每块模型输入补入对应 B，缓存包含 B 状态、generation、内容和人工编辑时间，模型返回与最终事务都验证输入未改变。缓存不纳入摘要自己写入的事件归属/整理时间，避免无意义重复付费请求。
- 手改 A 后，摘要不发送该原录音的旧 B 机器文本，人工修正优先；B 原文仍独立保留供查看。手改不自动重做已完成专题，用户点重新整理才重做。显式重转写的手改提醒与撤销保留。
- 数据库升至 44：43 加 textEditedAt，44 加 ASR token 字段。两种 DB35 兼容仍保留；官方 42/43 缺整体版表时幂等补齐，不覆盖已有 whole_transcripts/generation。升级前保留备份；不支持直接把 44 数据库交给旧版应用降级打开。
- 原音清理并存 B 待处理保护与未成功推送保护。只有启用、支持音频且显式选择音频的通道才可上传；通话与导入录音默认不推，旧配置缺新字段不会开启。目的地变化重建上传凭据，失败/取消不记成功。

## 隐私与权限

Manifest 无新增权限，本次不改变用户设置、不授予系统或文件夹权限。录音推送支持已有 WebDAV/S3 与新增手机文件夹；需用户选择授权的目的地。允许后会发送原音频及所选逐字稿，目的地改变可能重新上传。上传当前文件期间修改配置不能撤回已经发出的字节。

本地隐私删除只处理本地数据，远端已推送副本列为需要用户手动删除，不会自动删除远端。长期保留以及 B/上传待处理保护可能增加手机占用。

睡眠功能原有风险继续存在：启用后睡眠结果/标签进入备份，按配置进入模型分析及每日文档推送；完整备份可含已确认睡眠片段音频，不能笼统说所有录音永不离机。屏幕/播放信息按既有设置参与模型与备份。豆包 Agent Plan 凭据与按量凭据继续分开，失败不自动回退按量调用；备份含密钥的选项仍需用户自行保管。

## 验证

本轮最终验证通过：321 个不同 Android 用例（Release 逻辑测试，Debug Compose 界面测试）、shared JVM 497 个用例；修正后的定向复测无失败。Android 全部轮次测试执行时间合计约 80 秒，编译/lint 耗时另计。执行 :shared:check、:app:assembleRelease、:app:lintRelease、check_shared.py、check_devices.py；lint 为 0 错误、340 警告、26 提示。所有数据为合成，通道与模型使用模拟，不向真实渠道推送录音、不进行付费调用。

验证涵盖两种 DB35、真实定制 DB42→44 保留 whole/generation/A/引用并重新打开，专题 B 晚到/失败/仅 B/显式只 A/生成中编辑/缓存重用，手改与重转写撤销/提醒、字幕、A/B 视图切换、独立双 ASR/token、Typeless、备份恢复/隐私删除/原音保护、推送授权及目的地/失败/取消、Plan 与按量凭据隔离、禁用官方更新。首轮 317 个 Android 用例有 9 个失败；问题修正后仅重跑相关项，加跑字幕与双视图，未将首轮失败记为通过。初次 Kotlin 编译也暴露已移除的地址校验调用，改为由 Android 注入校验后通过。

首轮发现并修正：迁移夹具对省略的 nullable 字段使用 getBoolean；专题额外缓存指纹误含整理自己写入的归属字段；更新备份测试未区分系统自动重提与用户确认后取消。Release Compose 测试缺测试 Activity，界面交互改在带测试 manifest 的 Debug 变体执行，不向生产包添加测试 Activity。

没有安卓真机安装、长时间后台录音、实际 Typeless 争用、Mac 对齐服务联调或真实渠道上传验证。iOS 检查脚本因无 Xcode 未运行编译，不代表 iOS 通过。真机需核验升级后历史 A/B、手改与撤销、播放字幕、版本切换、系统后台限制和已有文件夹授权。
