# 定制版 0.5.6

基于已交付定制 0.5.5（467b407833b95fcef53c9e61e70e5bf4d6ff1132），合入正式上游 v0.5.6（adb2fa13d90a76b631492507ba65db7f3d70139a）。包名 app.resound，0.5.6-custom-asr.1，versionCode 99，ARM64，Room 44 不变。只更新 typeless-micfix。

## 行为与隐私

- 新增用户主动选择的“自动（含蓝牙）”；已有 Phone、Auto、指定设备及其保存值不变。USB/有线优先，随后 BLE、SCO，失败回手机。首次选择涉及 Android 附近设备权限；没有替用户授权，也不自动改旧设置。
- 合入未知媒体路由的保守扬声器判定，但不采用媒体会话时间重叠直接否定梦话：媒体记录不能证明耳机中的声音从扬声器外放。仅可靠外放标记/夜间信号排除派生梦话，原始录音和转写不改删。
- 夜间单段 M4A 只在点击导出后生成，未确认片段也可主动导出。读取、显示可用性及导出后复核使用实际保留规则：未确认按 expiresAt（含反馈更新），已确认按片段起点 90 天。过期、缺失或导出期间删除/到期不交付缓存；导出不更新原片期限。
- 删除日期不再用事件结束时间估算。导出缓存由维护或下次导出清理一天前的文件（不是准点擦除）；用户另存或分享的副本不受本地删除控制，需自行删除。没有新增自动上传、备份或推送目的地/授权范围。
- 429 仅分类显示固定限流、并发、过载或额度提示，普通探针、JSON 流式/非流式及对话流式均不回显 provider 正文；失败正文也不进入 trace 内容。
- 保留 Typeless 让麦、本地自定义分人、Mac 可配置对齐、每个原始 segment 独立 A/B 请求、手改优先、双版视图、会议块仅用于摘要、最近已应用 24 小时撤销和后置变化保护、隐私删除快照。没有跨 VAD、片段、会话或缺口拼接。官方 APK 自更新继续禁用。

## 设备限制

没有手机、Mac 或 Xcode；不宣称 Typeless 首击成功、真实蓝牙权限撤销/重连、OEM 冷启动路由、Mac 联调、AAC 硬件编解码/实际播放器播放已验证。M4A 生产路径保留 AAC 格式、单轨、时长和可读帧检查；导出回归使用模拟编码器验证生命周期，不能代替真机播放验收。iOS 检查脚本因缺 Xcode 未执行编译。
