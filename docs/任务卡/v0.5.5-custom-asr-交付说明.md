# v0.5.5 自编版交付说明

## 上游与定制

- 上游让夜间识别模型下载不再依赖一般环境音开关；没模型时先存本地候选，下载就绪后补识别。中断的夜晚在截止前可续记。新增最近一次重做的持久撤销入口，点“好”关闭任务后仍可找回。
- 保留 Typeless、本地分人、可配置 Mac 对齐、每原始录音的独立 A/B ASR、两套视图和手改优先、后台调度、备份删除、待处理 B 音频保护及官方 APK 更新禁用。不改变原录音、暂停、VAD、会话边界；会议块只用于摘要，不跨录音或缺口拼接。
- 撤销必须是已应用且从快照创建起未满 24 小时的最近一次；确认框之外的底层调用也执行同样检查。新增 A/B 或引用、编辑和后台整理改变参与记录时拒绝覆盖新数据。快照保存双版、generation、手改时间及引用，事务恢复只触及参与记录。
- 隐私删除清除含相关录音/事件的撤销快照；提示观察数据库变化，删除后不可通过旧提示恢复。收起撤销卡仅隐藏当前页面，重进/重启可再显示尚未过期的入口。“今天”显示事件重做/合并，“原话”显示重转写。
- 睡眠续记明确检查同一 windowId 和截止期，中断区间保留为缺口。候选读取仍为本机解码；测试通过注入合成 PCM，不接入模型或真实音频服务。

## 升级与隐私

Room 保持 44，schema 与上次交付完全相同，无新增迁移；现有设置保持不变。覆盖升级前保留备份，不支持向旧数据库版本降级。

Manifest 没有新增权限，不授予文件夹/系统权限。此次会在睡眠已开启、一般环境音关闭时自动从已有 ModelScope/GitHub 地址下载本地模型；镜像模型约 27 MB，GitHub 兜底归档约 111 MB，均沿用尺寸/hash 校验。候选音频留本机等待识别；未增加上传目的地、未扩大备份或音频推送授权。完整备份仍仅打包已确认睡眠音频，未确认候选路径从备份快照移除。

原有外发范围仍需知悉：睡眠结果/标签可按设置进入备份、模型分析和每日推送文档；已确认睡眠片段可进入完整备份。明确开启的音频通道可上传对应原音，通话和导入默认不推；远端副本不受本地隐私删除自动清理。待处理 B/未成功推送的保护可能增加本地空间占用。
