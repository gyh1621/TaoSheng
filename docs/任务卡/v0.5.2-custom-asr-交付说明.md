上游新增夜间睡眠、自动通话导入、一天线索、会议补跑与省电查询；v0.5.2 将睡眠数据纳入备份并支持早晨向已配置每日文档写入昨晚内容。合并 ImportSummary 时同时保留整体原文输入和上游通话文件名脱敏。

数据库从 38 升至 42：新增通话记录、睡眠表、speakerIntervals 和睡眠窗口字段。保留历史 fork35 与官方35 两种结构兼容迁移，并在 41→42 幂等补表以兼容官方 38～41 库；不使用破坏性重建。schema35/38 保留历史自编库结构，schema42 包含 whole_transcripts。升级前保留备份，升级后不要直接安装旧版读取新数据库。

官方 APK 更新继续禁用；补充冷启动安装回调和系统安装器入口的恢复闸，清除残留官方安装状态。删除上游误纳入最终树的 Python 字节码缓存；公开上游历史保留原样。LICENSE/NOTICE 保持不变。

## 权限与数据范围

本次 Manifest 未增加 uses-permission，仅增加未导出的安装中转 Activity；未授予权限、修改设备设置或扩大 Drive 共享。

睡眠总开关默认关闭；启用后 includeInPush、weeklyReport 等默认开启。周报统计文字可发送到已配置整理模型；关闭 includeInPush 不会单独阻止周报模型润色。每日推送可能包含入睡/起床时间、时长、觉醒、鼾声/咳嗽/梦话、置信理由及记梦文字，目的地为用户已配置的坚果云、Notion 或自定义接口等现有推送目标。

日常本地/云端增量分卷备份新增睡眠结果、片段元数据、标签/关联、反馈、梦境、周报及设置；该路径不复制睡眠音频文件，恢复结果不等于恢复片段播放。完整归档路径另会复制已确认的睡眠音频，未确认片段路径清空。夜间环境声音分类在本机进行；原有云端 ASR/整理机制仍可能上传正常录音/转写，不能笼统声称所有录音始终只在手机。

外放策略新默认是转写并整理；显式旧设置按迁移规则保留，旧版从未设置者使用新默认，可能增加送往现有 ASR/模型的外放内容。通话文件名提示词脱敏不等于语音正文自动脱敏。时间线删除会更新关联梦话，但独立睡眠记录需在睡眠功能中删除；全量隐私删除也处理睡眠数据。

此前已引入的屏幕使用/播放标题收集与远程公告仍存在：取决于系统权限及用户设置，应用使用/节目标题可能进入配置模型和备份；远程公告会访问 ModelScope/GitHub。本次未替用户授权。
