# 定制版 0.5.8

基于已交付 typeless-micfix 2869249afd9a644c4c3c10bd1460a852e2879498，合入正式 v0.5.8（1da331ac84063a44eaf02e19bcc15353eadf428c）。应用 app.resound，0.5.8-custom-asr.1，versionCode 103。只更新定制分支，保留 FSL-1.1-MIT LICENSE/NOTICE。

## 上游与定制

- 合入无输出超时标识、专题开始取消处理、空名称专题的生成标题展示/检索、本机 NPU 未就绪时 CPU 回退和按请求显示状态。生成标题只作为空名称时的展示值，不回写用户名称；仓库事务仍拒绝重复开始进行中的专题。
- 备用切换仅在保存的开关明确为 true 时启用，且只用已有有效配置；未设置和显式关闭均不切换，不自动写开关或新增模型。请求期间关闭也阻止继续切换。明确启用的用户继续沿用原配置。空流、心跳与推理/正文已有输出分别处理；问答流输出后不再切换。无备用仍交给原有业务缩小重试。这里的“无输出”不能证明服务商没有计费；显式开启备用意味着可能发生第二次请求。
- 不采用上游跨 5 秒停顿的短句合并。合并限于新本机结果、同一已知说话人、非重叠且间隔小于原有 800ms 停顿边界；句末标点和时间范围保留。每个原始 segment 仍各自识别，不跨片段/暂停/会话，也不重新加工旧记录或手改。自定义分人/对齐入口不经过此规则，整体 B 仍独立识别。
- 新专题诊断只导出数字编号、时间、枚举状态、计数和布尔标志；不输出自由文本阶段、错误/原因、标题、原话、提示或纪要。检查点位于 noBackupFilesDir，既有显式问题记录导出流程不变，不增加自动分享。
- 保留 Typeless 让麦、Phone/Auto/蓝牙 opt-in 与回退、Mac 对齐、双版与 whole pending 音频保护、手改优先、最近一次有效重做撤销、官方不同签名 APK 自更新关闭。备份默认/加密/路径与深度思考保持用户选择。

## 数据、权限和隐私

Room 仍为 44，44.json 与上一版字节一致；Manifest、模型来源及完整性配置无变化。没有新增权限、自动下载模型或对外上传目的地。NPU/CPU 回退只改变本次实际执行后端，不重写保存的选择。旧状态 actual 仅为过期运行提示，升级清除后按实际模型状态计算，保留模型、语言、ASR 来源与对齐设置。

继续保留原有隐私边界：已配置模型可能收到授权的原话/应用播放上下文；睡眠结果可能进入已启用的备份/每日推送，睡眠片段主动导出后的外部副本需用户自行删除。本轮不扩大备份、录音推送或分享范围，不替用户授权权限。
