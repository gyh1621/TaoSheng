# 上游 0.4.0 同步

## 范围

以已交付 code82 的 fork 提交 `5f2249776b9130ffb6c3f29500b98da595343d51` 为基线，合并正式上游 `v0.4.0`。版本为 `0.4.0-custom-asr.1`（83）。

- 保留 Typeless 麦克风让出、自定义分人/声纹、可配置对齐地址、每个原始 segment 的双版转写、各原文入口切换、备份/重做/清理保护。
- 不跨 segment 拼接，不更改 VAD、录音停顿或整理会话边界，不加入被否决的跨会话方案。
- 合并上游后台调度和错误分类；整体版仍待处理或尚可重试时保持重试，耗尽次数时等用户明确重转录或仅用切分版。其他已就绪段不受影响。
- 新调度会计算整体版独立待处理队列；本地切分版仍可离线处理，不被残留云端整体版卡住。
- 新首页搜索的原话结果也可切换查看所属原录音的整体版。检索索引仍沿用上游切分原话/事件，不把整体版伪造为逐句引用。
- 自编版不从官方更新通道检查、下载、安装 APK；手动检查给出维护者 Drive 更新说明，避免失去自定义功能。
- 保留上游 FSL-1.1-MIT 的 LICENSE.md / NOTICE.md；旧版的历史许可证不改写。
- 配置与凭据无硬编码；未提交签名、私网地址、录音或本机 SDK 路径。
