# 定制版 0.5.7

从定制 0.5.6（3837e5babecb6a9d4b6192f24fc4016c5c9fb080）合入正式 v0.5.7（8ef16fb16da78140b08e343d1cd4dc27c8a4bdb1）。包名 app.resound，0.5.7-custom-asr.1，versionCode 102，ARM64，Room 44/schema 不变。只更新 typeless-micfix。

## 保留选择，避免隐私和费用迁移

- 不采用上游默认/升级自动开启本机备份：初始化不写开关或目录，不把含凭据的归档自动放到共享 Downloads。新装、未设置、曾关闭、仅手动、重启和恢复均保持原有选择；显式开启的调度仍保留。既有加密逻辑和下载备份目录保持不变。用户主动选择的完整备份仍可能含凭据及原先允许的音频，应自行保管。
- 不采用强制开启“整理前先思考”的迁移。未设置保持原有效默认关闭，显式开/关不变，不触发自动增加费用的设置变更。
- 保留 Phone、原 Auto、主动启用蓝牙和指定设备的完整选择/回退逻辑，不采用上游排序列表的非等价迁移。指定设备不在时仍回手机；普通 Auto 不自动选蓝牙；已主动启用蓝牙时维持 USB/有线优先、BLE/SCO 后备。
- 转写提供方未设置时也保留原有效默认；已有 Local/Custom/Doubao 等选择不变，不自动切换提供方。上游本机识别优化可在已选择本机识别时使用。

## 合入的改进与定制保护

- 本机 ASR 在一次原始片段内部按停顿切到约 20 秒、最多 28 秒，硬切仅内部重叠；不改变录音、VAD、暂停或会话边界。分人按字时间映射，额外修正说话人区间外/空档不能认成下一人。恢复缓存含原 segment、音频指纹、长度、版本和分人配置。
- 自定义 A 仍用原片内部的本地分人切片和 Mac 对齐；B 使用原片独立请求，不靠 A 拼接模拟。手改优先、双版视图、最近已应用 24 小时撤销、后置变化及隐私删除快照保护保留。官方 APK 自更新继续关闭。
- 有已配置热词时，分说话人格式可带 definition。只对明确 definition 字段不兼容的 400/422 去掉字段重试一次；不对认证、限流、额度或其他输入错误重复请求；不回显服务商原文，继续保留 429 安全文本。
- NPU 模型按支持的骁龙芯片选择，原 SM8650 模型标识不变。镜像固定提交、原始 GitHub 回退源、归档和模型 SHA256/长度验证保留；六种 NPU 归档的预期 SHA256 和大小已与 sherpa-onnx 官方 GitHub release 资产 digest/size 核对一致；失败按既有规则回退 CPU。新增 Stub/Skel 按上游公开 tag 纳入，未独立重建第三方预编译二进制。
- 夜里短暂看手机后再睡不立即结束整夜，采用近期起床时间和已有窗口截止规则；保留原夜间启用设置、录音保留期、安全导出与缓存处理。不新增备份、自动推送目的地或权限。

## 验证

本轮只使用合成数据、模拟网络和通道，没有真实付费调用或向真实目的地发送录音。Android 相关用例共 430 个通过，shared JVM 527 个通过，shared Android Debug/Release 各 6 个通过，无剩余失败/跳过。应用用例累计约 87 秒，不含编译/lint，未跑无关全量 Android 测试。

覆盖两种 DB35、42→44 迁移及真实旧 Room44 合成双版/手改/generation/引用/撤销数据；备份未设置/关闭/手动/显式启用/重启/恢复、加密与路径；Phone/Auto/opt-in 蓝牙/指定设备回退与 Typeless 逻辑；ASR 片内切块/时间/分人空档、独立 A/B、模型镜像损坏/截断/取消与哈希校验；429 四类请求模式、热词明确字段回退与不重试；夜间续记、隐私删除、导出到期与缓存；双版和撤销 UI。

首次 shared 测试出现既有 429 模拟网络与虚拟时钟竞态，改为统一测试调度器后通过。首次应用测试出现旧语言标识断言与既有定制配置指纹冲突，核对前版生产逻辑未变，修正为“指纹失效、提供方不变”后重跑通过。没有将失败算成通过。

共用/设备边界检查通过，iOS 脚本因未安装 Xcode 跳过编译。最终 Release 构建和 lintRelease 通过；lint 报告 353 个 Warning、27 个 Hint，无 Error/Fatal，未宣称全部消除告警。

## 未覆盖

没有手机、Mac、Xcode 或真实服务联调；不宣称 Typeless 首击、真实蓝牙权限撤销/重连、各芯片 NPU、整夜睡眠、硬件 AAC 播放或实际服务兼容性已验证。模型来源/哈希策略及回退通过静态和模拟检查，不等于已下载并运行六种芯片模型。共享 Downloads 的用户主动备份副本、主动保存/分享的导出副本不受本地隐私删除控制。
