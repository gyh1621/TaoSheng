# 自定义转写双版：干净重建

## 范围

从公开 fork `2970a97` 重新实现，不沿用被否决的跨录音窗口方案。旧 code81 源码已不可恢复，本次重建其功能，并非恢复原始源码。

- 保留 Typeless 补丁；录音服务、VAD 分段、最大原始音频长度、原有整理停顿/会话规则不变。
- 自定义 ASR 的切分版：手机原有分人和停顿切片，独立可配置对齐服务，不要求 SenseVoice 权重。对齐不可用保留粗时间与文字。
- 整体版：每个现有原始音频 segment 完整原文件单次提交自定义 ASR，不按说话人或新增时长窗口再切，不跨 segment 拼接。
- 两版独立保存；整体版不伪造说话人、逐字时间或引用句。整理以同一录音两种识别补充上下文，不重复算事件；原会话边界不变。
- 整体版失败时暂停该段整理；用户可在整体版明确选择本次仅切分版整理，或重新转录重试，不静默降级。
- 两版纳入分卷备份和重做撤销快照。
- 各数据库原文展示入口可切换，包括历史无切分句子时。离线导出 SRT 预览仍显示对应导出文件，而非冒充当前数据库内容。
- 明确忘记时清空整个对应整体版，代次条件防迟到写回；后台音频清理保护待处理/失败整体识别。

## 边界

- 切分版全空、整体版有字时保留整体版并明确提示尚未自动整理。原事件体系依赖真实原话 ID，本次不伪造切分句或扩大事件来源模型。
- 接口明确返回截断标记时识别失败；接口若静默截断而不报告，客户端不能可靠识别。
- 未连接用户 Mac、未在用户手机实测。识别质量、Typeless 系统麦克风行为及设备端覆盖升级需真机验收。
- 本次不修改原有设置默认值，也不自动将既有历史全部上传；历史记录可手动重转生成两版。
